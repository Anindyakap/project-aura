# Project Aura — Start Here

This folder is the operating manual for continuing **Project Aura** with Codex while also learning TypeScript and web-development logic.

## How to use these files

1. Open the repository in Codex.
2. Give Codex `06_CODEX_MASTER_PROMPT.md` as the main instruction file.
3. Ask Codex to read `01_MASTER_CHECKLIST.md` before changing code.
4. Work on only the first unchecked item.
5. After each change, update the checklist and `02_PROJECT_SUMMARY.md`.
6. When a file is changed, add or update its explanation in `03_CODEBASE_GUIDE.md`.
7. Use `04_TYPESCRIPT_BEGINNER_GUIDE.md` and `05_LINE_BY_LINE_STUDY_WORKFLOW.md` while studying the code.

## Important limitation

These documents were produced from the manual documentation supplied for Aura. They describe the architecture and the files mentioned in those manuals, but they do **not** contain the complete current repository source code. Therefore, exact line-by-line explanations must be generated by Codex after it reads the real files in the repository.

## Recommended first Codex command

```text
Read all Markdown files in the documentation folder, especially 01_MASTER_CHECKLIST.md and 06_CODEX_MASTER_PROMPT.md. Then inspect the repository without changing anything. Compare the real codebase with the documentation, list any mismatches, and propose updates to the documentation. Do not implement a feature yet.
```

## Security note

Do not commit passwords, API keys, JWT secrets, database URLs, access tokens, or real customer data. Keep secrets in deployment environment variables and provide only `.env.example` placeholders in Git.
